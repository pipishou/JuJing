# ① 立项

五件套：**目标 → 关键动作 → 出口判据 → 实证 → 陷阱**；索引与流转规则见 `00-overview.md`。

## 目标

定「不做什么」比定做什么更要紧；M1 最小可信内核跑通。

## 关键动作

1. 现状盘点三张表（资产／卡点／红线，诚实口径不粉饰）
2. **诚信红线**先行（题集 40 拒 20 放：合规问题立项期一刀切，不留运营期返工）
3. **三条产品铁律**定稿（差异点不可动摇），后续功能照铁律裁决
4. M1 判据先于代码（whalemementor 09-12 M1 19/19 全绿即封版；mo-ai 内核 9/9 封版不恋战）
5. 治理底座第一天上线（INBOX＋决策台账＋状态机）
6. **准入四象限只做定位**（锚点`准入四象限`，2026-11 外部经验吸收）：立项时按「技术复杂度 × 风险」把每块工作标一格——①低复杂度低风险＝直接做；②低复杂度高风险＝人机协同（人定风险侧）；③高复杂度低风险＝拆小步试；④高复杂度高风险＝**本次不做**（写清回到哪张卡、什么条件下再议）。用途＝**分派与排期定位，不是门**：不评分、不设阈值、不据此卡任何卡（做成准入评分＝假门，`pitfalls.md#19`）；每季度校准一次即可，不随批次重算。

## 出口判据

M1 绿＋红线清单＋铁律三条＋台账可用；每块工作有象限格（④象限须写明「本次不做＋何时再议」）。

## 实证

whalemementor 09-12：M1 判据 19/19 全绿即封版，不恋战加功能。

## 陷阱

不立铁律就开写→功能蔓延失焦（`pitfalls.md#13`）。
