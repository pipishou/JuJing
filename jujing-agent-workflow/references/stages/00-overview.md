# 阶段索引与流转（聚鲸工作流）

> **分件制**（P2 起）：每阶段一件，**按号直取**——路由判定出阶段号后直接读对应分件，禁止全目录整读。
> **编号**：分件号与 `SKILL.md` 阶段序列**同号**（①立项…⑧反馈运营；⑤含发布与更新）。飞轮不占阶段位（内核，见 `self-optimization.md`）。
> **映射唯一事实源（P3 定）**：本件索引表是阶段号 ↔ 分件路径映射的唯一事实源；`stages.md` 指针件零映射复制（陷阱 #9 防双写；`SKILL.md` 仅入口速查）。
> **动作号坐标**：`⑤6`、`④4` 之类是 KB 溯源的**位置坐标**＝「阶段⑤分件的动作 6」，改号须同步 `knowledge/INDEX.md`「现落点」。
