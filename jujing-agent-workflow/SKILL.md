# 聚鲸 Agent 工作流 v2.3.3（配对校准棘轮＋BARS 行为锚＋校准锚冻结件，2026-10-17；`data/VERSION` 同值）

**内核**（不可变；改动须主版本＋人类确认）：**AI＋数据飞轮上的自优化** ＝ 六公理 ／ 四齿飞轮＋双回流 ／ 三硬机检（三绿·用户视角断言门·状态机）／ 五个控制点 ／ append-only＋棘轮。
**外壳**（开放扩展；新增必过四问并登记 → `references/evolution.md`）：阶段 ／ 形态 ／ 机制件 ／ 经验库 ／ 路由表。
**能力归属**：本 skill 只出**判据·模板·机检项·路由·锚点**；**业务能力归项目**（具体命令、平台配置、仓库路径与 tag 策略一律留项目侧；判据须过「换个项目仍成立？」）。已被否：路由脚本、向量检索/RAG。
**阶段序列**：①立项 → ②需求（含产品定稿）→ ③开发 → ④测试 → ⑤部署 → ⑥版本管理 → ⑦排障 → ⑧反馈运营。`stages/` 分件与本节**同号**（按号直取：①=`stages/01-inception` … ⑧=`stages/08-operations`；索引与流转见 `stages/00-overview`，旧「按动作名定位」写法已作废）；下文 ⑤⑥⑦ 指本序列。
**不使用**：单次脚本、纯问答、无交付物探索（此时是过度工程）。机制溯源见 `references/pitfalls.md`。

## 〇 路由即第一动作（唯一入口）

触发后首个动作不是读文件，而是**亮路由**（把「判错」前置到最便宜处）。两档：

**① 常驻一行（每次会话必出，硬要求）**：`路由：形态=X ｜ 阶段=Y ｜ 加载 N 件 ≈Z KB ｜ 依据「用户原话」｜ 纠偏：直接说「形态不对」`
**② 完整卡（判不准／高风险动作前／用户说「亮卡」时展开）**：五项模板与透明度守恒三条见 `references/routing.md` §一（不在此复制）。

**透明度守恒（D1）**：降频次不降可见——「依据」必引原话；判定若变须重出声明；用户质疑加载量须立刻给全卡。

**参数与判据**：唯一事实源＝`assets/params.json`（分节存预算／抽检池／WAL／rubric／编制／治理）——**文档只引用键名，不复制数值**；查值＝`python scripts/probe_usage.py size`（反查：锚点注册／漂移与死引用／参数键悬空／配置节消费者可落实／陷阱引用存在性）。
**铁律·不设硬上限·零硬编码（2026-09-27 用户令；锚点 `不设硬上限`）**：① 零硬编码——一切判据值只存 `params.json`，文档与代码只引键名；② 不设硬上限——大小/预算类数值（文件、会话、索引字数等）一律为**软目标观测线**：超线只提示、说明取舍，**禁止**作为机检非零退出门、验收否决项或跨轮追压字数的债；成本意识由路由按需加载＋减法纪律实现。缘起＝P1 两轮验收陷入「压文件大小」死循环（同根第二次复发，见 `evolution.md` #8/#18）：验收焦点永远＝行为覆盖与真实价值，不是文件字数。

## 一 六条公理（判据的判据）

1. **不信声明，信事实；不信自觉，信机制**——是事实就机检，是判断才留给人。落地＝判据（文档）＋可执行载体＋机检项三件齐（缺机检项只记候选，只写判据＝口号）；机检先决条件＝**判定面收窄**（门过宽⇒永远红⇒被绕过，陷阱 #19）。
2. **同源自审有结构性上限**——同上下文换帽子≠独立评审；解药＝异构的怀疑（G2.5）＋独立上下文复核。
3. **纪律产生复利，编制不产生**——价值来自三绿/留痕/测试复利，不来自角色数量。
4. **用户在流程里的位置决定纠偏成本**——发现越晚越贵，故用户对齐前置（G0）。
5. **绿测可能掩盖死功能**——测试绿 ≠ 接线了 ≠ 被消费了。
6. **流会作废，常才值钱**——只固化判据/题集/机制接线，不固化易变措辞。

## 二 形态补丁（加载模型＝骨架＋补丁）

阶段件只写「任何形态都成立的骨架」，形态件只写「本形态在各阶段的额外动作」⇒ 件数＝阶段数＋形态数，不组合爆炸。

| 形态 | 判据 | 文件 | 高发陷阱 |
|---|---|---|---|
| 全新产品 | 无上游、无存量、边界自主 | `forms/greenfield.md` | 边界漂移(#13)、绿测掩盖(#3) |
| 二开跟随上游 | 有上游＋有跟随义务 | `forms/forked-upstream.md` | 命名空间抢占(#18)、旧快照当现状(#16)、假配置面(#17) |
| 存量改造/迁移 | 在役系统/存量数据/不可逆步骤 | `forms/legacy-migration.md` | 数据不跨版本、可恢复性前置、回滚未演练 |

## 三 团队底座（细节 `references/roles-and-gates.md`）

**角色分工**：Orchestrator（不写码）／Builder（唯一 maker）／Adversary（KPI=找问题）／Steward（事实·成本）／Gatekeeper（门禁脚本化）＋双裁判 PM（产品正确性）× AI Manager（可靠性）；用户终审一票否决。
**四机制＋门序列**：Maker-Checker｜用户视角断言门（无断言禁 merge）｜状态机（`inbox→assigned→in_progress→review→done|failed`）｜G2.5（任一否决即打回）；门序 `[G0]→[G1/G1.5/G2]→[G2.5/G3]`。**授权红线**：git 必须用户明确下令；升级七类必须 @user（spec 偏离／删数据／新依赖／砍功能／AI 策略／方案取舍／放宽测试）。
**编制裁剪**：裁剪档与人数见 `params.json#team.scale_tiers`；全编制门槛＝`params.json#team.full_scale_min_people`。**不默认全编制**。

## 四 自优化（内核飞轮；命令与每轮协议见 `references/self-optimization.md`）

四齿咬合：**信号 WAL → 积累（同类达晋升阈值 `params.json#wal.promote_min` 即候选；**候选 ≠ 同类**——分组键 `(type, clause)` 只共享上位公理，故 `promote-check --digest` 强制打印同类性三问 `params.json#wal.cohesion_questions`、`mark-promoted` 必带 `--cohesion` 随行留痕；同根复发换了锚点时聚类键看不见，靠机器可读 `--chain` 字段让复发可复算）→ 落地（棘轮）→ 控制（人类 5 确认点）**，消费探针回流（痕迹）＋条款热度回流（`heat`：命中加分／空转扣分，权重带符号；**常态恒 0 退出**、非 0 仅配置错误一类 fail-closed＝观测非门）防条款空转。每轮 6 步：WAL → promote-check → 探针抽检＋热度回流 → 效果实测 → rubric 打分 → 人类确认晋升/退役。
**双回流**（测试/反馈＝对产品与开发的校验修正）：一次测试/反馈/事故必须产出**一对**——① 产品侧＝**卡**（含用户可见效果＋可机判定言）；② 经验侧＝**行**（`wal.py add`，带 clause 锚点）。**只做 ② ＝ 教训只被记录，没变成要修的卡。** 机制权威件＝`mechanisms/experience-loop.md`（两环咬合＋④⑧出口判据挂载＋全循环留痕复算＋姊妹 skill 边界；机检 `kb-lint ⑨`）。

## 五 演化纪律

- 只固化「常」，不固化「流」；**下沉 ≠ 删除**（移出正文者一律归档 `knowledge/`：索引 `INDEX.md`＋条目 `entries/`，带溯源＋状态＋复现计数，只增不减）。
- 每条机制必答：哪场事故催生／谁消费／何时退役；答不出→不改（`evolution.md` 扩展四问）。新增前先查重，**有则改旧不增新**（加法的前置是减法）。
- 版本号只进不退（棘轮）；演化数据存 `data/`（append-only）。**大小超线件只提示取舍（铁律·不设硬上限），不构成债**；行为/边界类未达标项仍登记 `evolution.md#三`，不得以放宽判据了事。
- **skill 自身版本指纹**（⑥版本管理判据用于本 skill，2026-09-28 令）：`data/VERSION`＝SKILL.md H1 标题＝frontmatter description 句首 v 号，**升版本三处同改**，改后必跑 `python scripts/probe_usage.py version` 自检亮证（缺失/不一致即红）——会话内凭 attached skill 描述的 v 号直接核对「加载的是不是最新」（改了≠部署了，入口指纹对上才算）。frontmatter 值含半角冒号须**整体加引号**（单形态判据——块写法虽 YAML 合法，但与 version 同行指纹门互斥，不采用；严格 YAML 宿主会因裸冒号**拒载整技能**，宽松解析宿主则不暴露——`selfcheck` ⑬ 机检；`version` 指纹正则兼容引号，两机检不得互斥）。**版本位语义**（2026-10-06 产品负责人令；2026-10-17 配对校准批修订判定口径）：判定优先配对差值——同裁判实例评冻结锚 X 与当前批 Y，Y>X 且过 `params.json#rubric.ratchet_floor` → minor 位递增（x.y.0）；LOCKED（含行无 anchor_avg 时退回历史最高绝对分的旧行为）→ 仅 patch 位递增（x.y.z＋1），如 2.2.0→2.2.1、2.3.1→2.3.2、2.3.2→2.3.3——版本号仍只进不退，LOCKED 批以 patch 位留痕改动。
