# 注意力 OS：后续规划 v1.0

- 日期：2026-11-01
- 状态：方向稿（待用户拍板）
- 目标：把“4–5 个并行 AI 任务”收成“1 个注意力队列”，并在两周内验证是否真的省精力
- 约束：不换运行时、不升级 DSH、不装 superagent、不增加可见 agent 数量

---

## 0. 一句话路线

> **先量，再减，再授权，最后并行。**
> 不先做“更多 agent”，先做“更少打扰”。

---

## 1. 四个阶段

### P0：基线（3 天，不改行为）

| 项 | 内容 |
|---|---|
| 目标 | 知道现在到底被切了多少刀 |
| 做 | 注意力账本、打断/切换/决策埋点、当前 4–5 个任务清单、每日负荷 1–5 分 |
| 不做 | 不改提醒、不加 agent、不改 UI |
| 验收 | 能回答：过去 72h 被打断几次、WIP 峰值、最常被什么打断 |
| 产出 | `runtime/attention/ledger.jsonl` + 基线报告 |
| 回滚 | 删除埋点即可，无行为变化 |

**关键**：不要一上来就“优化”。先拿到你自己的注意力数据，否则所有预算都是拍的。

### P1：收口（第 1 周）

| 项 | 内容 |
|---|---|
| 目标 | 同时只让你看 1 个决策、最多 3 件事 |
| 做 | WIP≤2；`/today` 三件事；`/queue`；`/park`；`/resume`；第 3 个任务强制停泊；一条日报 |
| 不做 | 不做多来源、不做团队、不做自动执行 |
| 验收 | 4 个任务时系统要求停泊 2 个；日报 ≤3 件；你能在 3 分钟内看完 |
| 指标 | WIP≤2；日报阅读 ≤3 分钟；队列 ≤5 |
| 回滚 | 关闭 WIP 门，恢复旧视图 |

### P2：授权（第 2 周）

| 项 | 内容 |
|---|---|
| 目标 | 让 bot 在你不在时也能推进，但不越权 |
| 做 | Mandate（scope/strength/policy_version/sender/expires）；默认 observe；owner 可签发当天授权；`/mandate`；负测试 |
| 不做 | 不做自动发布/删除/花钱；不做批量单向门授权 |
| 验收 | 无 mandate 的执行必红；observe 只写 would-do；过期自动失效 |
| 指标 | 每天“需要你拍板”≤3；授权覆盖的可逆动作占比 ≥50% |
| 回滚 | 全部退回 observe；只保留人工确认 |

### P3：并行（第 3–4 周）

| 项 | 内容 |
|---|---|
| 目标 | 4–5 个任务真正并行，但不抢你的注意力 |
| 做 | Router–Worker：团长只路由；每个 Work Item 独立 worker 会话；六行 handoff；`/focus`；注意力 ROI 周报 |
| 不做 | 不做通用多 agent 聊天；不做 agent 自由互相调用 |
| 验收 | 4 个并行任务时，团长上下文不爆；你只处理 3 张票；worker 失败可重派 |
| 指标 | 打断 ≤3/天；决策 ≤3/天；切换 ≤5/天；值得 ≥70%；漏单向门 0 |
| 回滚 | 回到单会话 + 人工转发 worker 结果 |

### P4：扩展（首单后，按需）

- 其他 AI 任务来源接入（剪贴板/文件/任务卡）
- 团队/老板只读视图（T1）
- DSH bundle 分发实验（不接 superagent 运行时）
- 第二行业包

## 2. 两周成功/失败判据

### 成功（至少 4 条）

- 同时活跃任务 ≤2，且没有“忘了的活”
- 每天主动打扰 ≤3，且 ≥70% 你认为值得
- 你每天花在“管理工作”上的时间 ≤10 分钟
- 至少 1 个真实场景在 ≤3 次打扰内完成
- 你能说出“这周 AI 帮我省了哪一段”

### 失败（任一即停）

- 连续 3 天不打开 `/today`
- 打断 >5 次/天，且“不值得”>30%
- 队列 >10，且没有停泊/放弃动作
- 你觉得“用它比不用更累”
- 出现漏掉的单向门

失败后不硬撑：降级为“只做周报 + 人工确认”，保留账本，回滚行为。

## 4. 资源与成本

- 开发：P0 0.5–1 天；P1 1–2 天；P2 1–2 天；P3 2–3 天
- 运行：本地零新增依赖；飞书消息免费额度内
- 机会成本：不接 superagent、不做多租户、不做 App
- 失败成本：主要是 1–2 周开发；可用“只做 P0/P1”止损

---

## 5. 不做什么（冻结）

- 不增加第 6 个可见角色
- 不做“每个任务一个群”的 IM 结构
- 不做实时状态播报
- 不做自主发布/删除/付款
- 不做通用 Agent 市场
- 不把 DSH 升级当作产品前提
- 不用 star 数/消息数证明产品价值

## 7. 风险登记

| 风险 | 概率 | 影响 | 缓解 |
|---|---|---|---|
| 假紧迫，打扰反而变多 | 中 | 高 | 单向门清单 + 每日“不值得”反馈 |
| 藏事，停泊任务被忘 | 中 | 高 | 队列老化提示 + 周复盘 |
| 用户绕过 WIP | 高 | 中 | 返回停泊选择，不硬拒；记录破例 |
| Mandate 滥用 | 低 | 高 | 最小 scope + 过期 + 逐次确认 |
| Router 上下文仍爆 | 中 | 中 | 只读索引 + 六行 handoff |
| 实现拖成平台 | 高 | 高 | 每阶段只做一件事；P4 才扩展 |
