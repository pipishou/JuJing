## 日常三件事

```powershell
# 1) 打开工作台（首屏=工作事项台）
start http://127.0.0.1:8787/

# 2) 健康检查（应显示 pack=workops、industry=工作任务管理）
curl http://127.0.0.1:8787/api/health

# 3) 改了代码/配置后重启服务（需要管理员）
cd D:\work\产品类\个人产品\bot-2\JuJing\bot-team
powershell -NoProfile -ExecutionPolicy Bypass -File server\restart_services.ps1
```

数据都在 `bot-team/runs/<任务号>/`（report.json、四卡 loop/、签名、事件日志），
工作事项账本在 `bot-team/runtime/workitems/current.json`，
飞轮遥测在 `bot-team/.telemetry/*.jsonl`，决策账本在 `bot-team/.junshi/ledger.md`。

## 移动任何目录之前：这 5 处是绝对路径依赖

1. `bot-team/server/services/jujing-botteam-ui.xml` → `<workingdirectory>`
2. `bot-team/server/services/jujing-octop.xml` → `<workingdirectory>`（当前是 `bot-2` 根，因为 `OCTOP_HOME` 指向 `.octop`）
3. 计划任务 ×4（`Jujing-*`）的 Arguments 里的 `D:\work\产品类\个人产品\bot-2\JuJing\bot-team\...`
4. `server/run_octop.ps1`、`server/run_ui.ps1`、`server/restart_services.ps1` 里的路径
5. 环境变量：`OCTOP_HOME`、`OCTOP_CARD_HOOK`、`BOT_RUNS_ROOT`、`BOT_LEDGER_ROOT`、`BOT_WORKITEMS_FILE`、`BOT_PACK`

改完必须**以管理员重装服务**（`server/services/install_services.ps1`），否则服务起不来。

## 变更约定

- 产品代码改动在 **bot-team 仓**提交；方法论/文档改动在 **JuJing 仓**提交。
- 每个决策落 `bot-team/.junshi/ledger.md`（D-0xx 行，append-only），拍板件落 `bot-team/.junshi/decision-cards/`。
- 临时文件不要放工作区根：放 `_archive/tmp-<日期>/`，或直接删。
- 公开仓库边界：代码/模板/脱敏 demo/产品文档/审计/账本快照入库；真实工厂原始数据、业务凭据与密钥不入库。

```powershell
# 管理员 PowerShell 执行
cd D:\work\产品类\个人产品\bot-2\bot-team
powershell -NoProfile -ExecutionPolicy Bypass -File server\migrate_out_of_juijing.ps1
```

脚本会：停两个服务 → 删联接 → 把目录搬到 `bot-2\bot-team` → 在原位建反向联接 → 改服务 xml 工作目录 → 重装并启动服务 → 健康检查（失败自动回滚）。
